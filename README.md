# Customer Segmentation using K-Means Clustering

This project is an end-to-end Machine Learning web application built using K-Means Clustering and Streamlit.

## Project Overview

The application predicts customer categories based on:

- Annual Income
- Spending Score

The model groups customers into different segments for business analysis and marketing strategies.

---

## Features

- Customer Segmentation using K-Means Clustering
- Data Visualization
- Business Insights
- Silhouette Score Evaluation
- Interactive Streamlit Web App
- Real-time Customer Prediction

---

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
